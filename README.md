# UluP Spatial

Your UluP Spaces project, in mixed reality on Meta Quest. Grab, move and connect real project nodes as 3D objects floating around you — in AR passthrough or full VR.

Submitted to Meta Horizon Store (App Lab) and Sidequest
Early access APK: see [Releases](../../releases) or download directly from [ulupstudio.com](https://www.ulupstudio.com)
Trailer: https://youtu.be/_Nu6KphKIz8

Built with WebXR + React Three Fiber, same account and data as [UluP Spaces](https://www.ulupstudio.com/spaces).

Made by [UluP Studio](https://www.ulupstudio.com).
